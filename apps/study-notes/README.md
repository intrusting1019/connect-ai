# 밑줄 — 학습 필기 노트

노트 한 장을 **제목 · 대주제 · 소주제 · 내용 필기 · 미션**으로 나눠 적고, 소주제만 보고 내용을 떠올리는 방식으로 복습하는 한 파일짜리 웹 앱입니다.
설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있습니다.

## 기능

- **글 필기** — 제목 아래에 대주제를 세우고, 대주제마다 왼쪽 칸에 소주제, 오른쪽 칸에 내용 필기. 소주제 줄은 `Ctrl+Enter`로 추가.
- **미션** — 필기한 뒤에 할 일(문제 풀기, 암기, 과제)을 체크리스트로 적고, 끝내면 체크. 목록에 `미션 1/2`처럼 진행 상황 표시.
- **손필기** — 펜(3색·굵기 3단계), 형광펜, 지우개(획 단위), 되돌리기, 쪽 추가. 펜·터치·마우스 모두 지원.
- **복습** — 내용 필기를 가리고 소주제만 보여 줍니다. 모두 떠올리면 다음 복습이 1 → 3 → 7 → 14 → 30일로 멀어지고, 헷갈리면 내일 다시 봅니다.
- **정리** — 과목, 태그, 고정, 검색, "오늘 복습" 모아 보기.
- **내보내기** — 노트 한 개를 Markdown(.md, 대주제 `##` · 소주제 `###` · 미션 체크박스)으로, 전체를 백업(.json)으로 저장하고 다시 가져오기.
- 라이트(줄 노트) / 다크(칠판) 테마는 기기 설정을 따릅니다.

## 데이터가 저장되는 곳

| 여는 방법 | 저장 위치 |
| --- | --- |
| `index.html`을 직접 열거나 정적 호스팅 | 그 브라우저의 `localStorage` (`miljul:v1:` 접두어) |
| Claude 아티팩트로 게시 | 보는 사람 계정의 비공개 저장소 (`db` 기능, `data/users/<id>/…`) |

브라우저 저장은 그 기기·그 브라우저에만 남으므로, 메뉴의 **백업 내보내기**로 가끔 파일을 받아 두세요.

## 실행

```bash
# 그냥 열기
open apps/study-notes/index.html

# 또는 로컬 서버로
npx serve apps/study-notes
```

글꼴(Gaegu, IBM Plex Sans KR)은 Google Fonts에서 불러오며, 오프라인이면 시스템 글꼴로 대체됩니다. 그 밖의 외부 의존성은 없습니다.

예전 구성(단서 · 필기 · 요약)으로 저장된 노트는 열 때 자동으로 새 구성으로 옮겨집니다. 단서는 소주제로, 요약은 마지막 소주제 줄로 남습니다.
